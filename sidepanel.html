        To let Cloudy read a page, first click Cloudy's toolbar icon while that
        tab is active; buttons inside this panel do not grant access. Only the
        main page's rendered text is read (not iframes, images, canvas or other
        pages). Form values and editable text are never read, but visible text
        can still contain personal information. It goes only to your local
        Ollama, is kept in memory, and is not stored.
