        Stop cancels the browser's request. It does not prove Ollama stopped
        computing; the server may finish the current generation on its own. During an
        approved action, Stop cancels it only if it has not been dispatched yet; it
        never undoes an action that already ran.
      
            
      
            
        Cloudy can read ordinary http and https pages without a toolbar click.
        It cannot read chrome:// pages, the Chrome Web Store or other pages
        Chrome restricts. If you set Cloudy's Site access to "On click" or "On
        specific sites", click Cloudy's toolbar icon on the tab you want (buttons
        inside this panel do not grant access). Only the
        main page's rendered text is read (not iframes, images, canvas or other
        pages). Form values and editable text are never read (not even to name a
        control), but visible text can still contain personal information. It goes only to your local
        Ollama, is kept in memory, and is not stored.
